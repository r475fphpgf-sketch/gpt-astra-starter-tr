# GPT-Astra Starter (Türkçe, Basit MVP)

Bu repo, iPhone üzerinde kullanılabilecek basit bir sohbet arayüzü ve FastAPI tabanlı backend içeren starter projesidir. RAG (Chroma) entegrasyonu için örnek dokümanlar ve OpenAI entegrasyon şablonu içerir.

Özellikler
- Tek sohbet penceresi (mobil uyumlu, basit HTML/JS)
- FastAPI backend: /chat endpoint
- Chroma (vector DB) + sentence-transformers embeddings (örnek dokümanlarla)
- OpenAI entegrasyonu için placeholder (OPENAI_API_KEY .env içine eklenmeli)
- Dockerfile + docker-compose ile kolay başlatma
